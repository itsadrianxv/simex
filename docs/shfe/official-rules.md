# 上期所官方规则核查（simex 第一版）

核查范围仅限以下上海期货交易所（SHFE）官方页面（访问日期：2026-09-25）：

- [上海期货交易所交易规则](https://www.shfe.com.cn/regulation/exchangerules/rules/202606/t20260603_831934.html)
- [交易时间](https://www.shfe.com.cn/services/calenderandholidays/tradinghours/)
- [上海期货交易所螺纹钢期货业务细则](https://www.shfe.com.cn/regulation/exchangerules/productrules/202512/t20251231_829962.html)

## 已确认的规则

### 交易时段与集合竞价

交易时间页面把螺纹钢（RB）列在“螺纹钢、热轧卷板、燃料油、石油沥青、天然橡胶、合成胶、纸浆、胶版印刷纸、20号胶、低硫燃料油”组：

- 夜盘集合竞价申报：20:55–20:59；集合竞价撮合：20:59–21:00；连续竞价：21:00–23:00。
- 日盘集合竞价申报：08:55–08:59；集合竞价撮合：08:59–09:00；连续竞价：09:00–10:15、10:30–11:30、13:30–15:00。
- 页面注记：某交易日夜盘交易时段从上个工作日的 21:00 开始。页面同时以“各品种交易时间”字段展示上述时段；节假日/特殊安排应以交易所公告为准。

通用《交易规则》第二条第（五）至（八）项定义交易日、日盘和连续交易：日盘通常为北京时间 09:00–11:30、13:30–15:00，连续交易为日盘之外由交易所规定的时间。RB 细则第七条明确 RB 日盘为上午 9:00–11:30、下午 1:30–3:00及交易所规定的其他交易时间。

通用《交易规则》第二条第（二十三）项规定：开盘价是开市前五分钟内经开盘集合竞价产生的成交价格；若未产生成交价格，以当日竞价交易第一笔成交价为开盘价。这确认了集合竞价的申报/撮合窗口及“无成交时开盘价取首笔成交价”的结果，但没有规定未成交申报单在集合竞价结束后的具体去向（见未确认项）。

### 排序、撮合与成交价

通用《交易规则》第二十三条：交易所计算机撮合系统按“价格优先、时间优先”排序；买入价大于或等于卖出价时自动撮合。撮合成交价等于买入价（bp）、卖出价（sp）和前一成交价（cp）三者中的居中价格：

- bp ≥ sp ≥ cp：成交价 = sp；
- bp ≥ cp ≥ sp：成交价 = cp；
- cp ≥ bp ≥ sp：成交价 = bp。

该条还说明涨跌停板等特殊情况，交易所可另行规定撮合成交方式。

### 指令变更、撤销与未完全成交存量

通用《交易规则》第二十一条：交易指令包括限价指令及交易所规定的其他指令；指令当日有效。在交易所规定时间内，非期货公司会员、境外特殊非经纪参与者和客户可以在指令成交前变更和撤销。指令未能一次全部成交且未撤销的，其存量仍存在于交易系统内，继续参加当日竞价交易，交易所另有规定的除外。

通用《交易规则》第二十四条确认：交易指令经撮合成交后交易即告成立，交易所按规定发送成交回报。

## RB 合约参数

RB 业务细则：

- 第三条：交易单位 10 吨/手。
- 第四条：报价单位 元（人民币）/吨。
- 第五条：最小变动价位 1 元/吨。
- 第七条：交易时间为 9:00–11:30、13:30–15:00 及交易所规定的其他交易时间（夜盘的具体窗口以交易时间页面为准）。
- 第四十六条：涨跌停板幅度为上一交易日结算价 ±3%。

## 页面未明确规定的事项

下列内容在上述三个官方页面中没有找到可直接引用的明确规则，不能冒充为上期所规则：

- **FAK/FOK**：页面未明确给出 FAK（立即成交剩余撤销）、FOK（立即全部成交否则撤销）指令类型、字段或执行语义。官方来源未确认，不能冒充规则。
- **集合竞价未成交单去向**：第二条第（二十三）项只规定集合竞价未产生成交价格时的开盘价取值；第二十一条规定一般指令未完全成交且未撤销时继续参加当日竞价交易，但上述页面没有专门说明集合竞价未成交申报单是否自动转入连续竞价、是否自动撤销或如何保留其时间优先级。官方来源未确认，不能冒充规则。
- **原生改单语义**：第二十一条允许成交前变更，但页面没有说明交易系统层面的改单是“保留原申报时间优先级”还是“撤单后重新申报”、是否允许只改价格/数量及改动对队列的影响。官方来源未确认，不能冒充规则。

## 对 simex 第一版的实现约束

1. 使用价格优先、`rx_time` 优先的订单队列；连续竞价成交价使用第二十三条的买价、卖价、前一成交价三者居中公式。第一笔成交没有当日最新价时，simex 使用已验证的上一交易日结算价作为 fallback。
2. 按交易时间页面配置 RB 时段，明确区分 20:55–20:59/20:59–21:00 夜盘集合竞价、21:00–23:00 夜盘连续竞价，以及日盘的集合竞价和三个连续竞价区间；将夜盘归属于下一个 trading day。对应的可执行配置在根目录 `simex.json`。
3. 通用规则明确允许成交前变更/撤销，但没有公开原生改单的优先级语义。simex 将改单建模为撤原单、按新 `rx_time` 重新申报，并把它标为模拟器选择。
4. 官方页面没有确认 FAK/FOK 的术语和字段。simex 仍提供明确标注为模拟器扩展的限价 IOC/FOK，以及市价单剩余量立即取消；这些语义写入 `simex.json`，不冒充 SHFE 指令定义。
5. 官方页面没有明确集合竞价未成交单的去向。simex 采用已确认的模拟器策略：只允许限价 DAY 单进入集合竞价，按最大成交量、最小未匹配量、最接近参考价、较低价格选择成交价，未成交限价单携带原始 `rx_time` 进入连续竞价。
